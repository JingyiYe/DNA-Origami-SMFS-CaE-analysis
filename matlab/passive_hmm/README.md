# Passive-mode HMM analysis scripts

This folder contains MATLAB scripts for processing passive-mode optical-tweezers force-time trajectories and performing molecule-level hidden Markov model (HMM) analysis.

## Folder contents

```text
matlab/passive_hmm/
├── README.md
├── hires_passive_processing.m
├── hires_passive_split.m
├── isomerization_split.m
└── pyHMM_oneMolecule.m
```

## Script descriptions

### `hires_passive_processing.m`

Processes high-resolution passive-mode data files.

The script concatenates segmented `stepdata.time`, `stepdata.force` and `stepdata.extension` arrays, plots the force-time trace, allows manual selection of passive-mode regions, and saves the selected boundaries and indices in a `_bounds.mat` file.

### `hires_passive_split.m`

Splits selected passive-mode regions into individual trajectory files.

The script reads `_bounds.mat` files generated by `hires_passive_processing.m`, extracts each selected passive-mode region, and saves it as a separate `_split.mat` file containing `pdata.Time`, `pdata.Y_force` and `pdata.labels`.

### `isomerization_split.m`

Separates kinetically distinct regions within passive-mode trajectories when needed.

The script reads `_split.mat` files, allows manual selection of isomerization-like regions, and saves the corresponding trans-like and cis-like trajectory segments as `_trans*.mat` and `_cis*.mat` files.

### `pyHMM_oneMolecule.m`

Performs molecule-level HMM fitting and kinetic analysis.

The script reads `_split.mat` files from a single molecule or trap position, calls a Python `hmmlearn`-based HMM workflow, compares candidate fits using the Bayesian Information Criterion (BIC), extracts state means, fitted state trajectories, dwell-time-derived rates and confidence intervals, and saves the results as a `_pyfit.mat` file.

## Required helper functions

These scripts call additional helper functions that should be available on the MATLAB path, including:

```text
FilterAndDecimate
LA_pyHMM2
LA_hmm_lifetimes_n_v2
```

Users should place the required helper functions in the same folder or add their location to the MATLAB path before running the analysis.

## Requirements

- MATLAB R2018a or later
- Python 3.8 or later
- `hmmlearn` 0.2.7
- NumPy
- SciPy
- pandas

The recommended Python environment is provided in the root-level files:

```text
environment.yml
requirements.txt
```

## Basic workflow

1. Select passive-mode regions from high-resolution force-time traces.

   ```matlab
   hires_passive_processing
   ```

2. Split the selected regions into individual `_split.mat` files.

   ```matlab
   hires_passive_split
   ```

3. Optionally separate trans-like and cis-like trajectory regions.

   ```matlab
   isomerization_split
   ```

4. Run molecule-level HMM fitting and kinetic analysis.

   ```matlab
   pyHMM_oneMolecule
   ```

## Outputs

The scripts generate passive-mode HMM analysis outputs, including selected trajectory segments, HMM state assignments and dwell times. These outputs are used for downstream state assignment, transition-rate analysis and folding-landscape reconstruction.

## Notes

These scripts use interactive file selection and manual region selection. Users should verify selected passive-mode regions, baseline stability, force calibration, filtering settings and single-tether quality before interpreting HMM-derived state assignments or kinetic parameters.
